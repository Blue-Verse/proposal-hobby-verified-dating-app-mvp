핵심 요구사항 분석

  • 소셜 로그인 + 휴대폰 본인 인증 — 소셜 계정 간편 가입과 SMS 본인 인증으로 신뢰 기반 가입 흐름 구성
  • 프로필 등록·관리 + 취미/성향 키워드 — 사진·정보 등록과 매칭용 키워드 설정으로 추천 알고리즘의 기반 데이터 확보
  • 추천 피드 (스와이프/리스트) — 나이·지역·취미 기반 필터가 적용된 이성 추천 노출
  • 좋아요·매칭 신청/확인 + 매칭 성공 화면 — 양방향 호감 일치 시 매칭 성사 및 전용 성공 화면 노출
  • 1:1 실시간 채팅 — Firebase/Supabase 실시간 동기화 기반 즉시 대화
  • 푸시 알림 (FCM) — 매칭·채팅 이벤트 실시간 알림 + 딥링크 진입
  • 관리자 백오피스 — 인증 사진 심사·가입 승인 시스템 및 사용자/매칭 운영 관리
  • 산출물 — 앱 설치 파일 및 양대 스토어 등록, 소스 코드 원본, 관리자 매뉴얼

제안 포인트

  1. 매칭 플랫폼 도메인 직접 경험 전이 — Connectin(프로필 기반 매칭·근거리 탐색·1:1 보안 메시징) 수행 경험을 데이팅 추천·매칭 흐름에 그대로 적용합니다.
  2. Firebase/Supabase 실시간 + 푸시 검증 패턴 — Calendar Share에서 Firebase RTDB 3종 리스너 기반 실시간 채팅과 7종 FCM 푸시를 구축한 경험으로, 채팅·알림을 안정적으로 구현합니다.
  3. Flutter 단일 코드베이스 양대 마켓 출시 — Fortune App 등에서 기획·디자인·개발·스토어 심사까지 단기 풀패키지 출시를 수행하여, iOS/Android 동시 출시 일정을 보장합니다.
  4. 신뢰 기반 인증 흐름 설계 — 휴대폰 본인 인증과 관리자 인증 사진 심사 승인을 결합해, 프리미엄 데이팅에 필수적인 신뢰 게이트를 MVP 단계부터 견고하게 구성합니다.
  5. 확장 대비 데이터 모델 — 취미·성향 키워드와 매칭 로그를 정형화 적재하여, 향후 추천 고도화(가중치·큐레이션) 도입에 바로 활용할 수 있도록 설계합니다.

PRD (Product Requirements Document)

프로젝트 요구사항을 정의하고 기능 범위를 명확히 합니다.

1. 프로젝트 배경 및 목적

취미 및 프로필 인증을 기반으로 신뢰할 수 있는 이성을 추천받고, 양방향 호감 표시를 통해 매칭 및 대화를 나눌 수 있는 프리미엄 데이팅 앱 MVP를 구축합니다. 인증 기반 신뢰 게이트와 취미·성향 중심 매칭으로 기존 외모 중심 데이팅 앱과 차별화하고, iOS/Android 동시 출시로 시장 진입을 빠르게 검증하는 것을 목표로 합니다.

2. 사용자 정의

사용자 유형설명주요 기능
일반 사용자인증을 거쳐 매칭을 이용하는 앱 이용자가입/인증, 프로필·키워드 등록, 추천 피드, 좋아요·매칭, 실시간 채팅
관리자인증 심사·운영을 담당하는 백오피스 사용자인증 사진 심사, 가입 승인/거절, 사용자·매칭 관리, 신고 처리

3. 기능 요구사항

3.1 가입 및 인증

  • [필수] 소셜 로그인 (Google / Apple, 카카오 확장 가능)
  • [필수] 휴대폰 본인 인증 (SMS)
  • [필수] 관리자 승인 기반 가입 완료 (인증 사진 심사)

3.2 프로필 및 키워드

  • [필수] 사진·기본 정보 등록 및 프로필 관리
  • [필수] 취미 및 성향 키워드 선택·수정

3.3 추천 및 매칭

  • [필수] 추천 피드 (스와이프 또는 리스트)
  • [필수] 기본 필터 (나이·지역·취미)
  • [필수] 좋아요·매칭 신청/확인, 양방향 일치 시 매칭 성공 화면

3.4 채팅 및 알림

  • [필수] 1:1 실시간 채팅 (Firebase/Supabase)
  • [필수] 푸시 알림 (FCM) — 매칭·채팅 이벤트

3.5 관리자 백오피스

  • [필수] 인증 사진 심사 및 가입 승인/거절
  • [필수] 사용자/매칭 조회·관리, 신고/차단 처리

4. 비기능 요구사항

항목요구사항
성능추천 피드·채팅 메시지 즉시 반영 (실시간 리스너 기반)
보안/프라이버시본인 인증·인증 사진 접근 통제, 민감 정보 암호화 저장, 신고/차단 체계
확장성키워드·매칭 로그 정형화 적재로 추천 고도화 대비
호환성iOS / Android 최신 2개 메이저 OS 버전 지원

5. 기술 제약사항

  • 모바일: Flutter 단일 코드베이스 (iOS/Android 동시 출시)
  • 백엔드: Firebase(Auth/Firestore/FCM/Storage) 중심, 필요 시 Supabase(Postgres/Realtime) 병행
  • 관리자: Next.js 기반 경량 백오피스 (또는 Firebase 콘솔 보조)
  • 스토어 정책: Apple/Google 데이팅 카테고리 심사 가이드라인 준수

6. 범위 외 사항 (Out of Scope)

  • AI/머신러닝 기반 고도화 추천 알고리즘 (MVP는 키워드·필터 기반)
  • 인앱 결제·유료 구독 등 수익화 기능 (차기 단계)
  • 영상 통화, 그룹 채팅 등 확장 커뮤니케이션 기능
  • 다국어/글로벌 출시 (MVP는 국내 단일 언어 기준)
